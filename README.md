# C8855 Mac

浜松ホトニクス **C8855-01** のカウントをMacで表示・保存するネイティブアプリです。
メーカー非公式の試作版。ブラウザーやPythonは起動に不要です。

## ダウンロード

[最新版のアプリ](https://github.com/krs893/c8855-mac/releases/latest)からZIPをダウンロードし、解凍した **C8855カウンター.app** をアプリケーションフォルダーへ移動します。
macOS 13以上、Apple Silicon / Intel向けの共通アプリです。Intelでの実機動作は未確認です。
Appleの公証は未取得です。起動を拒否された場合は、入手元を確認してからmacOSの「システム設定 → プライバシーとセキュリティ」で許可してください。

## 使い方

1. 電源・信号の適合を確認したSPADのSIGNALを、対応する同軸ケーブルでカウンターのSIG INへ接続します。
2. C8855-01をUSBでMacに接続します。1台だけ接続してください。
3. 起動時にUSB接続を自動確認します。後から接続した場合は左側の「接続を確認」を押します。測定命令はまだ送信しません。
4. 最初は計数時間を「1秒」に設定し、「測定開始」を押します。
5. 「停止」で終了します。「測定の終了」を「時間を指定」にすると、指定時間で終了します。

SPAD未接続では光子の測定はできません。実機テスト時の0カウントはSPAD未接続の結果です。
**カウンターのDC OUTをSPAD電源に接続しないでください。** このアプリはSPAD電源やPMT電源を操作しません。

## 画面の見方

- 上部：USB接続状態と「測定開始」「停止」。未接続時は開始できません。
- 左側：計数時間・終了条件・グラフの表示設定。
- 中央：最新値とグラフ。縦軸・横軸には数値目盛りを表示します。
- 下部：CSVの記録状態・ファイル名・保存操作。
- 右上の「？」：接続方法、操作、検証状況。

## リアルタイム表示・設定

- 計数時間：0.1 / 0.2 / 0.5 / 1秒。1回分のカウントが届くたびに更新します。
- 測定中に計数時間を変更して「変更して再開」を押すと、停止・保存後に新しい設定で再開します。
- 横軸：直近10 / 30 / 60秒。縦軸：counts/sまたは1回分のカウント、自動または手動の上限。
- 「表示を固定」はグラフだけを固定します。「表示を再開」で最新の表示に戻ります。測定と記録は続きます。

表示するのは**カウントの時間変化**です。オシロスコープのような電圧パルス波形や、個々の光子の到着時刻は取得しません。
横軸は計数時間×取得回数です。USBの受信時刻とは区別してください。
画面に保持するのは最新3000点ですが、CSVには全取得点を記録します。

## データ保存

CSVは `~/Library/Application Support/C8855Counter/measurements/` に自動保存します。
「保存フォルダー」でFinderに表示し、測定終了後に「CSVを書き出す…」で別の場所へコピーできます。
列は受信時刻、取得番号、計数時間、カウント、counts/s、Unix受信秒、単調時計の受信秒、セッションIDです。
counts/sはカウント÷設定時間で、検出効率・デッドタイムの補正はありません。
連続測定では保存容量に注意してください。

## 外部コードからのリアルタイム計測

アプリを起動したまま、C++やPythonから開始・停止・連続受信ができます。
[C++クライアントと実行例](cpp/README.md)は実行時にPythonを使いません。
左側の「API受付中」を確認してください。[APIの使い方とPython例](API.md)。

```sh
python3 example_realtime.py --gate 0.1 --seconds 10
```

最短0.1秒ごとのカウントを送信します。受信時刻はゲート開始時刻ではなく、画面表示との厳密な同期は未実装です。

## 検証状況

2026-10-05、Apple Silicon MacとC8855-01で、USB認識・1秒ゲートの10回取得・停止・CSV保存を確認しました。SPAD未接続で全取得値は0でした。
非ゼロのカウント精度、短いゲート、長時間測定、Intelでの動作は未確認です。研究に使う前にWindows版や既知のパルス入力と比較してください。
通信エラーを0カウントや架空データに置き換えません。
停止はUSB読み取り中に数秒かかる場合があります。終了時にも停止処理を行います。
外部トリガー・複数台接続・メーカーAPIの完全互換は対象外です。

## 開発

Xcodeの開発ツールとPython 3を用意し、このフォルダーで実行します。

```sh
python3 build_app.py
python3 -m unittest discover -s . -p 'test_*.py'
xcrun swiftc PlotData.swift PlotDataTests.swift -o /tmp/c8855-plot-tests
/tmp/c8855-plot-tests
```

- `NativeApp.swift`：画面。
- `CounterModel.swift`：連続取得・CSV保存・外部操作。
- `LocalAPI.swift` / `APIConfig.swift`：ローカルAPIと設定の検証。
- `counter_client.py` / `example_realtime.py`：Pythonからのリアルタイム受信。
- `PlotData.swift`：表示範囲・縦軸の計算。
- `USBBridge.c` / `.h`：USB通信。模擬libusbを使うテストは実機を操作しません。
- `counter.py` / `reference_session.py`：通信確認用のPython参照実装。アプリ実行時は使いません。
- [PROTOCOL.md](PROTOCOL.md)：通信の根拠と実機確認結果。
- [vendor/README.md](vendor/README.md)：同梱libusbのライセンス・ソース入手先。

アプリのソースはMIT、同梱libusbはLGPL-2.1-or-laterです。メーカーのDLL・マニュアルは配布しません。
不具合は[Issues](https://github.com/krs893/c8855-mac/issues)へ、macOS・Macの種類・操作・表示されたエラーを添えて報告してください。
